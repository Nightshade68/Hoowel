# Watch UI

## Home

- Time/date
- Battery
- Today's StrideAI workout
- Music shortcut
- Run shortcut

## Run

- Elapsed time
- Distance
- Current pace
- Heart rate when available
- Lap
- Workout step and target
- Music mini-player
- Pause/stop

## Music

- Artwork
- Track / artist
- Progress
- Previous / play / next
- Shuffle / repeat
- Playlist/library

## Coach

- Today's recommendation
- Current workout instruction
- Short alerts
- Sync with phone for full AI analysis

The visual implementation should remain hardware-neutral until display resolution, touch behavior, and graphics SDK are confirmed.

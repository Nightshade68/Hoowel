# StrideAI HooWel Watch Prototype

This is the first hardware-independent UI prototype for the HooWel → StrideAI project.

## Run

Open `index.html` in a browser. No hardware, SDK, or firmware flashing is required.

## Screens

- Home: time, battery, recent pace and heart rate
- Run: live-run placeholder with distance, pace and HR
- Workout: today's workout and coaching guidance
- Coach: concise StrideAI coaching message

## Target

The layout is designed around the reported 240×282-class HooWel/IDW16 display while keeping all hardware-specific code out of this first prototype.

## Safety

This prototype does not communicate with or modify the physical HooWel. Stock firmware remains untouched.
